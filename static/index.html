GPXTo 🚴

구글·네이버·카카오 지도 링크, 상호, 주소를 붙여넣으면 현재 위치에서 그곳까지의 도로 자전거 경로를 만들어 가민 커넥트 / IGPSPORT로 보냅니다.

-거리
-획득고도
-예상시간

사용 방법

  1. 붙여넣고 찾기 — 지도 앱에서 공유한 링크, 또는 상호·주소
  2. 장소를 고르고 위치 권한을 허용하면 경로 완성
  3. 보내기 버튼 → 공유창에서 가민 커넥트 또는 IGPSPORT 선택
📲 홈 화면에 설치하기 (공유 메뉴에 등록)
  1. Android: 크롬 메뉴(⋮) → 앱 설치
  2. 설치 후 구글맵·네이버지도·카카오맵의 공유 창에 GPXTo가 나타납니다
  3. 공유로 열면 자동으로 찾기가 실행됩니다

경로: BRouter · 지도 데이터: OpenStreetMap contributors
