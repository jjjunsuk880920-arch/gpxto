사용 방법

  1. 출발지: 현재 위치 그대로, 또는 직접 지정
  2. 목적지: 링크·상호·주소를 붙여넣고 찾아서 고르기
  3. 경로 만들기 → 보내기로 가민 커넥트 / IGPSPORT 선택
📲 홈 화면에 설치하기 (공유 메뉴에 등록)
  1. Android: 크롬 메뉴(⋮) → 앱 설치
  2. 설치 후 구글맵·네이버지도·카카오맵의 공유 창에 GPXTo가 나타납니다
  3. 공유로 열면 목적지가 자동으로 채워져 찾기가 실행됩니다
